# System card

Purpose: demonstrate research-to-operations translation across battery evidence, forecasting, physical simulation, and optimization. It is local-first, has no telemetry, accepts no executable/model uploads, and stores only run configurations/results in SQLite.

Known limits include small benchmark scope, household-reference load, scenario scaling, weather-driven rather than measured PV, uncalibrated forecast bands, simplified hourly storage physics, and research-only dispatch. Not intended for BMS, utility control, grid protection, safety, trading, or guaranteed savings/resilience.
